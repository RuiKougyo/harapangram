プライバシーポリシー

制定日：2026年10月21日

かんたんに言うと
  • メールアドレス・電話番号・本名・住所は集めません。
  • 投稿は、相互フォローの友だちにしか見えません（サーバー側で制限しています）。
  • パスワードとあいことばは暗号化（ハッシュ化）して保存し、運営者にも読めません。
  • 広告や行動追跡のしくみ（Cookie による追跡など）は使いません。データを売ることもありません。
  • 退会すると、あなたのデータはすべて削除されます。

1. 集める情報

情報使い道見える人
名前・ID・プロフィール画像友だちに表示、ID 検索つながっている人（ID を知っている人は検索で名前と画像だけ見られます）
パスワード・あいことばログイン、パスワード再設定だれも読めません（ハッシュ化）
投稿（写真・お店・感想・満足度・場所）友だちとのシェア、地図相互フォローの友だち
いいね・コメント反応と通知その投稿が見える人
フォロー・ブロック表示範囲の決定フォローは相手、ブロックは本人のみ
行きたいリスト・通知の既読あなた専用の機能本人のみ
招待コード友だちの招待コードを受け取った人
通報の内容ルール違反への対応通報した本人と運営者

写真に位置情報（Exif）が入っていても、アプリで縮小・切り抜きしたときに取り除かれ、保存されません。

2. 端末に保存するもの

ログイン状態と、見たストーリーの記録などを、お使いのブラウザ（localStorage）に保存します。追跡用の Cookie は使いません。

3. 外部サービス

本サービスは次のサービスを使って動いています。これらの事業者は、サービス提供のためにアクセス記録（IP アドレス、ブラウザの種類、日時など）を一時的に保存することがあります。

  • Supabase（データベース・ログイン・写真の保存）：データは東京リージョンに保存されます。
  • GitHub Pages（画面の配信）
  • Google Fonts（文字のフォント）
  • OpenStreetMap / Nominatim（お店の検索ボタンを押したときだけ、入力したお店の名前を送ります）

4. 第三者への提供

法律にもとづく場合を除き、あなたの情報を本人の同意なく第三者に渡しません。

5. 安全のための取り組み

  • すべての通信は暗号化（HTTPS）されています。
  • データベースは行単位のアクセス制限（RLS）で、見てよい人だけが読めるようにしています。
  • 写真は非公開の保存場所に置き、見られる人にだけ期限つきのリンクを発行します。
  • あいことばは5回まちがえると30分間ためせなくなります。

6. 削除・訂正

名前・画像・投稿はアプリからいつでも変更・削除できます。マイページの「アカウントを削除」で、あなたのデータをすべて削除できます。サーバーのバックアップからも一定期間ののちに消えます。

7. 変更

このポリシーを変更するときは、アプリ内でお知らせします。

8. お問い合わせ

GitHub の Issues から連絡してください（だれでも読めるので、個人情報は書かないでください）。
