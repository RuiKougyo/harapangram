利用規約

制定日：2026年10月21日

この規約は、「腹ぱんぐらむ」（以下「本サービス」）を使うときのルールです。登録した時点で、この規約に同意したものとします。

1. 本サービスについて

本サービスは、相互フォローしている友だちどうしで、行ったお店の写真や感想をシェアする無料のサービスです。個人が運営しています（以下「運営者」）。

2. アカウント

  • 登録には、名前・ID・パスワード・秘密のあいことばを決めます。メールアドレスや電話番号は不要です。
  • パスワードとあいことばは、自分で大切に管理してください。ID とあいことばの両方を忘れると、アカウントは元にもどせません。
  • 13歳未満の人は、保護者の同意を得てから使ってください。
  • 1人で多数のアカウントを作ったり、他人になりすましたりしないでください。

3. 投稿について

  • 投稿した写真や文章の権利は、投稿した本人にあります。
  • 投稿は、相互フォローしている友だちにだけ表示されます。運営者は、サービスの運営と通報への対応に必要な範囲でのみ投稿を確認することがあります。
  • 自分で撮った写真や、使ってよい写真だけを投稿してください。他人の顔がはっきり写った写真は、その人の許可を得てください。

4. してはいけないこと

  • 法律に違反すること、犯罪につながること
  • 他人やお店への悪口、いやがらせ、差別、つきまとい
  • うそのレビュー、お店からお金などを受け取って書く宣伝（ステマ）
  • 他人の個人情報（住所・電話番号など）を書くこと
  • 他人の著作権や肖像権を侵害すること
  • 本サービスのしくみを壊したり、ほかの人のデータを不正に見ようとしたりすること
  • 大量の自動アクセス、スパム

5. 通報とブロック

困った投稿・コメント・ユーザーは、各画面の「通報」から知らせてください。相手をブロックすると、おたがいの投稿が見えなくなります。運営者は、ルール違反があると判断した場合、予告なく投稿の削除やアカウントの停止をすることがあります。

6. 退会

マイページの「アカウントを削除」から、いつでも退会できます。退会すると、投稿・写真・コメント・フォローなど、あなたのデータはすべて削除され、元にもどせません。

7. サービスの変更・停止

本サービスは無料で提供しているため、機能の変更や、保存容量の上限・障害・運営上の理由によるサービスの停止や終了をすることがあります。終了する場合は、できるだけ事前にアプリ内でお知らせします。

8. 責任について

運営者は、本サービスが正しく動くよう努めますが、データの消失や、投稿内容をもとにした行動（お店選びなど）で生じたトラブルについて、運営者に故意または重大な過失がある場合を除き、責任を負いません。ユーザーどうしのトラブルは、当事者どうしで解決してください。

9. 規約の変更

この規約は必要に応じて変更することがあります。大切な変更は、アプリ内でお知らせします。変更後も使い続けた場合は、変更に同意したものとします。

10. お問い合わせ

アプリ内の「通報」、または GitHub の Issues から連絡してください（Issues は誰でも読めるので、個人情報は書かないでください）。
